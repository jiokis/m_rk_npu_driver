## 1. 三个数字的关系（现在是自洽的）

| 口径 | 收益 | 依据强度 |
|---|---|---|
| **多核靶子 20 tile/提交** | **12.83 ms** | **实测达到过** ✅ |
| docs/87 曲线减 50% | 18.13 ms | 无依据的假设 |
| docs/87 曲线减 75% | 27.20 ms | 无依据的假设 |
| 去冗余拷贝 | 2.11 ms | 正确性已验证 ✅ |

**⇒ 12.83 ms 是目前「合并提交」这条路上**最有依据**的数字** ——
靶子来自实测（多核自己装过 20~21 tile），不是假设的融合度。

**⇒ 它落在「减 25%（9.07 ms）」与「减 50%（18.13 ms）」之间**，与曲线自洽。

## 2. ★ 三个模型「已优于靶子」是个有意思的结果

`mnasnet0_5`（3 提交/166 tile = 55 tile/提交）、`mobilenet_v2`（56）、
`regnet_x_400mf`（113 提交/3147 tile = **27.8 tile/提交**）——
**它们已经超过了 20 tile/提交这个多核靶子。**

* `mnasnet`/`mobilenet_v2`：**整体可融合**（无 Concat/SE/分组卷积）⇒ 轻松超过
* `regnet_x_400mf`：**有 22 个分组卷积却达到 27.8** ⇒ 说明**分组卷积不是硬约束**

**⇒ 这削弱了 docs/58 的一条推断**：我当时说「分组卷积会切碎提交」，
但 `regnet` 用 22 个分组卷积达到了 27.8 tile/提交 —— **比多核靶子还高**。

⚠️ **不是推翻**（受控实验确实测到分组卷积使提交数 7→13），
**而是说：分组卷积的影响可以被其它因素补偿。** 这需要重新审视。

## 4. 教训（本轮新增）

1. **★★ 把「有依据」和「无依据」的数并排显示，使用者才知道该信哪个。**
   工具现在把曲线标成 `[无依据的假设]`、靶子标成 `[有实测依据]`。
   **只给数字不给依据强度，等于把判断责任推给使用者而不给材料。**
2. **★ 靶子本身也会暴露旧推断的问题。** `regnet_x_400mf` 用 **22 个分组卷积**达到
   **27.8 tile/提交**（高于靶子）⇒ 与 docs/58「分组卷积切碎提交」的推断**张力明显**。
   **新结论要拿去和旧结论对撞 —— 不一致的地方就是下一个问题。**
3. **★ 「已优于靶子」也是结果，不是空结果。** 三个模型收益为 0 ——
   这本身说明**它们已经没有合并空间**，优化应该去别处找（例如带宽、或核数选择）。
   **零收益要写明原因，否则会被当成「没算」。**
