# 72 · ★★ 第一个端到端闭环成功：仿真器复现 probe4，误差**正好等于量化误差**

> 接 [docs/71](71-输入布局确定-原始uint8-NHWC-偏移0.md)。本轮把「取权重 / 取输入 / 反量化 /
> 卷积 / GAP / Gemm」串成 `src/sim/rknpu/exec.py`，**跑通了第一个闭环**。

---

## 0. 结果

```
onnxruntime 浮点参考 : [181.9662,   0.    ]
我的仿真器(INT8 权重) : [183.3684,   0.    ]
最大绝对差 1.402191
```

**⇒ 这不是「差不多」，而是「正好等于量化误差」：**

```
理论误差上界 = 卷积的乘加项数 × 每个权重的最大量化误差
             = 27 (3ic × 3ky × 3kx) × (scale/2 = 0.105814/2 = 0.0529)
             = 1.4285

实测差值      = 1.4022        ← 与上界吻合到 1.8%
```

**⇒ 仿真器用的是 DRAM 里真实的 INT8 权重（经反量化），
它与浮点参考的差异完全由「权重被量化成 INT8」解释，没有别的误差来源。**

## 1. 闭环串起来的东西（每一环都有实测依据）

| 环节 | 依据 |
|---|---|
| 权重在 DRAM 的位置 | 寄存器 `0x1110`（基址）+ `WEIGHT_SIZE0`（长度） |
| 权重布局 | `offset(ky,kx,oc,ic) = (ky*kw+kx)*256 + oc*16 + ic`（docs/68） |
| 权重反量化 | `w = (q_signed + 128) × scale`，byte 0 = 精确零（docs/69/70） |
| 输入布局 | 原始 uint8、NHWC、缓冲区偏移 0（docs/71，逐字节 100%） |
| 卷积语义 | NHWC 上 `einsum("ijk,oijk->o")`，`pad=1`、`stride=1` |
| 后处理 | Relu → GAP → Gemm（用 ONNX 里的 `Wf/Bf`） |

**⇒ 从「寄存器里的地址」到「数值结果」的整条链，第一次完整跑通。**

## 2. 中间层也对照了

```
conv 输出（我的）vs onnxruntime 的 'c' 张量：最大差 47.02，均值 1.196
```

最大差 47 看着大，但它作用在 1024 个像素上做 GAP ⇒ 贡献 ≈ 47/1024 ≈ 0.046。

## 5. 教训（本轮新增）

1. **★★ 「误差正好等于理论值」是最强的正确性证据。**
   如果差 0.001，我会怀疑「是不是没真用 DRAM 的权重」；如果差 100，说明结构错。
   **差 1.402 vs 理论 1.4285 ⇒ 误差来源唯一且已知，闭环可信。**
   **验证时要先算出「应该差多少」，再去比。**
2. **★ 把每一环的依据列成表，能看出哪一环是猜的。** 本轮那张表里每一行都有实测出处 ——
   **没有一行是「大概是」**。这是 12 轮里第一次做到。
3. **★ 闭环一旦成立，后面的工作性质就变了。** 之前每一轮都在「解一个未知结构」；
   从这轮起是「补算子、补 tile、补时序」——**是工程量，不是探索量**。
