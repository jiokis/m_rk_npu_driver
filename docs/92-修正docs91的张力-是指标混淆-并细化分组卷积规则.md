# 92 · 修正 docs/91 的「张力」：是**指标混淆**；并细化「分组卷积」规则

> 接 [docs/91](91-把多核靶子变成逐模型收益-12.83ms.md)。那里我写了一条「张力」：
> `regnet` 用 22 个分组卷积达到 27.8 tile/提交（高于靶子 20），
> 与 docs/58「分组卷积切碎提交」矛盾。**本轮查证：没有矛盾，是我把两个指标当成一个了。**

---

## 1. 两个指标是独立的

```
模型                  conv  提交  tile  提交/conv  tile/提交  tile/conv  分组
mnasnet0_5             52    3   166    0.06      55.3      3.2    17
mobilenet_v2           52    3   169    0.06      56.3      3.2    17
shufflenet_v2_x0_5     56   63   499    1.12       7.9      8.9    19
resnet18               20    5    74    0.25      14.8      3.7     0
squeezenet1_0          26   22   191    0.85       8.7      7.3     0
googlenet              57   35   402    0.61      11.5      7.1     0
regnet_x_400mf         71  113  3147    1.59      27.8     44.3    22
efficientnet_b0        81   88   318    1.09       3.6      3.9    16
densenet121           120  183  2572    1.52      14.1     21.4     0
```

* **`提交/conv`** = 每层有多少个提交**边界**（docs/58 的受控实验测的是这个）
* **`tile/提交`** = 每个提交里**装了多少 tile**（docs/90 的靶子测的是这个）
* **`tile/conv`** = 每层被切成多少 tile（**独立变量**）

**`regnet` 的 `tile/conv = 44.3`**（是 `mnasnet` 的 3.2 的 **14 倍**）⇒
它**同时**有很多提交边界（1.59/conv）**和**很多 tile/提交（27.8）。

**⇒ 两个指标互不矛盾，**没有张力**。docs/91 那条注释是我把两个不同的量当成了一个。**

---

## 2. ★ 但顺带发现了一条**更精确的规则**

看「分组卷积」那一列：

```
mnasnet0_5       17 个分组  提交/conv = 0.06   ← 最低！
mobilenet_v2     17 个分组  提交/conv = 0.06   ← 最低！
shufflenet       19 个分组  提交/conv = 1.12
efficientnet     16 个分组  提交/conv = 1.09
regnet_x_400mf   22 个分组  提交/conv = 1.59   ← 最高
```

**`mnasnet`/`mobilenet_v2` 各有 17 个分组卷积，提交/conv 却最低（0.06）！**

区别在**分组的类型**：
* `mnasnet`/`mobilenet_v2`：**depthwise**（`group == in_ch`）
* `regnet_x_400mf`：**部分分组**（`group ∈ {2, 4, 10, 25}`）
* 受控实验 `ab_group`（docs/57）：`group=8`，`ch=64/128` ⇒ **部分分组**

**⇒ 精确的规则：`部分分组`会切碎提交，`depthwise`（全分组）不会。**

**⇒ 这解释了 docs/56 那条跨模型相关性为什么失败（R²=0.016）**：
我当时把 **depthwise 和部分分组混成一类**（都算「group>1」），
**两类效应相反，混在一起互相抵消** ⇒ 相关性归零。

**⇒ 而且这**强化**了 docs/57 的教训**：当时我说「跨模型相关性不能用来否证机制」，
现在知道了**具体错在哪**：不是「混杂因素多」，而是**我把两个效应相反的机制合成了一类**。

## 3. 修正后的结论

| 项 | docs/58/91 的说法 | 修正 |
|---|---|---|
| 分组卷积 → 切碎提交 | 笼统的「分组卷积」 | **只有部分分组**（`1 < group < in_ch`）切碎；depthwise 不切 |
| regnet 的 27.8 tile/提交 与 docs/58 有张力 | 「张力」 | ❌ **没有张力**：`提交/conv` 与 `tile/提交` 是独立指标，regnet 的 `tile/conv=44.3` 解释了它 |
| 跨模型相关性 R²=0.016 的失败原因 | 「混杂因素多」 | **更具体**：depthwise 与部分分组的效应相反，被我合成一类 |

## 4. 教训（本轮新增）

1. **★★ 两个指标看起来在说同一件事时，先验证它们是否真的相关。**
   我拿 `提交/conv`（受控实验）和 `tile/提交`（靶子）对比，以为在同一个尺度上 ——
   **它们的分母分子都不同**。**比较两个量之前，先写清各自的定义。**
2. **★★ 「把两个效应相反的机制合成一类」是相关性失效的具体原因。**
   docs/56 我用「group>1」同时包含了 depthwise 和部分分组，
   **两者对提交数的效应相反**（一个不切、一个切）⇒ 相关性被抵消成 0。
   **这比「混杂因素多」精确得多，也更容易避免：分类时要检查「类内是否同向」。**
3. **★ 修正自己的结论时，要顺手把「为什么会错」也修正。** docs/91 我只写了「有张力」；
   本轮不仅否掉了张力，还**精确定位了 docs/56 相关性失败的机制**。
   **错误的根因往往比错误本身更有价值。**
