## 5. 教训（本轮新增）

1. **★★★ 日志里的 pass 名字是「流水线地图」，比任何推断都直接。**
   我否掉了 12 条假设才确定「切分在 tiling 层」，
   而**日志里一直写着 `RKNNTilingPass`** —— 我只是没去数 pass 名字。
   **拿到一份 verbose 日志，第一件事应该是提取 pass 序列。**
2. **★ 「给现象起名字」是逆向的关键一步。** 我之前把现象叫「提交切分」「权重布局」
   （**我的**名字）；编译器把它们叫 `RKNNTilingPass` / `RKNNWeightTransposePass`
   （**它的**名字）。**用它的名字去搜，才能找到它的代码。**
3. **★ 33 个 pass 里我关心的只有 4 个。** 不必理解全部流水线；
   **按「我否证清单的指向」去挑靶点**，就能把范围从 33 缩到 4。
