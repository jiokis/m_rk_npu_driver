## 1. ★★ 本轮最重要的结论是**方法论**的：上轮两个否证全错

`docs/56` 我用**跨模型相关性**否掉了两个假设：

```
假设 A：布局算子（Concat/Reshape/Transpose）⇒ R² = 0.040 ⇒ 判「否掉」
假设 B：分组/深度可分离卷积            ⇒ R² = 0.016 ⇒ 判「否掉」
```

**受控实验的结果：A 错、B 也错。**

```
Concat 受控 A/B ：7 → 19 提交（2.71×）   ⇒ 假设 A 是**对的**
分组卷积受控 A/B：7 → 13 提交（1.86×）   ⇒ 假设 B 是**对的**
```

### 为什么跨模型相关性会给出**完全相反**的答案

因为混杂：`mnasnet0_5` / `mobilenet_v2` 各有 52 个 conv、17 个 depthwise，
却只有 **3 次提交** —— 它们的**整体可融合性**（无 SE、无分组、无 Concat）
把所有局部效应都盖住了。相关性把这批点当成「分组卷积多但提交少」的证据，
于是把真实的正相关拉成了 ~0。

**⇒ 结论：跨模型相关性不仅能「发现线索」，而且**不能**用来「否证机制」。
一个 R²≈0 的跨模型相关，只说明「在这批模型上线性不可见」，不说明「没有因果」。**

**这是我在这个目标里第三次犯同一类错误**（把「我没观察到」当成「不存在」）：
1. docs/36：拿错参照物 ⇒ 「39 个上游未定义寄存器」（实际 2 个）
2. docs/47 §8：拿读地址当必要条件 ⇒ 「死代码」（实际判据无效）
3. docs/56：拿跨模型相关性当否证 ⇒ 两个假设「否掉」（实际都成立）

**三次的根因完全相同。** 这次我把它写成一条硬规则：

> **「否证」只能来自「必要条件」或「受控实验」。
> 相关性、观察不到、参照物不对 —— 这三样都不能用来否证。**

## 2. 试着建预测式：**因果有了，定量规律还没有**

既然三个驱动都确认了，我试着拟合一个提交数的预测式（9 个真实模型）：

```
提交数 ~ 1 + Conv + 分组 + SE + Concat      R² = 0.82

  截距 −34.2    Conv 1.21    分组 0.43    SE 1.14    Concat 1.16

  densenet121     预测 183.6  实测 183   +0.3%   ✅
  efficientnet_b0 预测  89.9  实测  88   +2.1%   ✅
  shufflenet      预测  60.2  实测  63   −4.5%   ✅
  googlenet       预测  47.3  实测  35  +35.2%   ✗
  regnet_x_400mf  预测  62.2  实测 113  −44.9%   ✗
  mnasnet0_5      预测  36.0  实测   3   **+1099%**  ✗✗
  mobilenet_v2    预测  37.1  实测   3   **+1137%**  ✗✗
```

**`mnasnet0_5` / `mobilenet_v2` 被高估 11 倍** —— 因为 `Conv` 那一项的系数（1.21）
完全是**伪相关**：它把「这批模型有很多 conv」当成了「conv 会切提交」，
而事实是**纯卷积链会被完全融合**。

去掉 `Conv` 项再拟合，系数也**不迁移**：
按 `3 + 5.0×分组 + 0.2×SE + 2.9×Concat` 算，`shufflenet` 会得到 144 而实测是 63（高估 2.3×）。

**⇒ 诚实的结论：**
* ✅ **因果**：SE / Concat / 分组卷积**各自**都会增加提交数（受控 A/B 证据）
* ❌ **定量预测式**：**还没有**。系数在模型之间不迁移，`Conv` 项是伪相关。
* 原因推测：这些效应**不是可加的** —— 一个模型如果整体可融合（如 mnasnet），
  个别「难融算子」的影响会被吞掉；只有在**整体不易融合**的模型上才显现。
  **这提示存在阈值/饱和效应，而不是线性叠加。**

## 3. 可操作的结论（针对具体模型）

| 模型 | 提交 | 可动的手术 | 预期 |
|---|---|---|---|
| `densenet121` | 183 | **62 个 Concat** —— 是最大来源 | 减少/合并 dense 连接（**改结构，精度风险高**） |
| `efficientnet_b0` | 88 | **17 个 SE** | SE 换局部池化 ⇒ 精度换速度 |
| `regnet_x_400mf` | 113 | **22 个分组卷积** | 分组改普通卷积 ⇒ 参数/算力代价 |
| `shufflenet_v2_x0_5` | 63 | Reshape/Slice/Transpose×103 | channel shuffle 是核心机制，难动 |
| `mnasnet`/`mobilenet_v2` | 3 | **无可动** | 撞带宽墙（docs/55） |

⚠️ **三项手术都要改模型结构 ⇒ 都是精度换速度，不是白拿的。**
本轮的价值在于**把「哪个结构在付代价」指出来了**，而不是给出无损优化。

## 5. 教训（本轮新增）

1. **★ 「否证」只能来自「必要条件」或「受控实验」。** 这是我在这个目标里
   **第三次**犯「把没观察到当成不存在」的错（docs/36 / docs/47 §8 / docs/56）。
   前两次我各写了一条教训，**但没写成硬规则**，所以第三次又犯了。
   这次写成可执行的判据：
   > **相关性、观察不到、参照物不对 —— 这三样都不能用来否证。**
2. **★ 伪相关会伪装成「有效模型」。** 那个 R²=0.82 的拟合里，`Conv` 系数 1.21
   看起来完全合理，还给出了 densenet 的 +0.3% 精确预测 —— **但它对 mnasnet 错了 11 倍**。
   **一个高 R² 的模型可以在最关键的样本上错得离谱**；要盯着**最大残差**，不是只看 R²。
3. **★ 受控实验的结论是「单因素」的，不能直接叠加。** 我证明了三个驱动各自有效，
   但这**不蕴含**「它们的效应可以相加」。**从「A 有效、B 有效」到「A+B 的效应可预测」
   中间隔着相互作用项。**
4. **本轮没有产出无损优化，这是要如实说的。** 三个驱动都是结构性的，
   动它们就要动模型 ⇒ 精度换速度。**把「代价在哪」指清楚本身有价值，但不该包装成「优化方案」。**
