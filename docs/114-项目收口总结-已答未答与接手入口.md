## 5. 方法论收获（贯穿 33 轮，10 条）

1. **公开 API 优先于盲探**（布局盲探 6 轮，`hybrid_quantization_step1` 一直可用）
2. **接口发现优先于机制猜测**（20 轮机制 vs 2-3 轮接口）
3. **验证的分辨力必须匹配结论强度**（4 次同族错误）
4. **否证只能来自必要条件或受控实验**（相关性两次给出相反答案）
5. **受控实验只改一个变量**（`ab_group` 改了两个 ⇒ 归因存疑）
6. **矛盾是假设错误的信号**；**荒谬的结果是判据**（收益 102%、63 ms > 总时长）
7. **算不出来的量改成曲线就能交付**；**机制答不清时改成边界问题**
8. **教训要写进代码，不只是文档**（`optimize.py` 的必填参数与依据标注）
9. **诊断性问题与交付性问题要分开**（追不影响决策的解释 = 资源错配）
10. **止损条件要在开始前写下并兑现**
