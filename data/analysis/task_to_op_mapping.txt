# 关键寄存器（实测语义）：
#   CNA(513).4136 = 空间尺寸（特征图边长）
#   CNA(513).4368 = 输入张量地址（随 task 单调递增）
#   DPU(4097).16416 = 疑似权重地址（三次重复中取值不同）

# ── resnet18 的 task 序列（74 个）按空间尺寸切段 ──
#   79:112 | 82-85:56 ×4 | 86-90:28 ×5 | 91-95:14 ×5 | 96-100:7 ×5 | 102-103:1 ×2
#   ⇒ 与 resnet18 特征图逐一对应：stem(112) / layer1(4 conv) / layer2(5) / layer3(5) /
#     layer4(5) / GAP+fc(2)
#   ⇒ 一个 task = 一个算子在**一个核上**的一次执行
#
# ── ★★★ 序列重复 3 次，权重各不相同、输入相同 ──
#   task  79: 权重=4282006528  输入=4283531264
#   task 105: 权重=4282074624  输入=4283531264   ← 权重不同、输入相同
#   task 129: 权重=4282140928  输入=4283531264
#   ⇒ 与 RKNNDuplicateWeightPass + RKNNMultiSurfacePass 一致：
#     权重复制 3 份（每核一份），三核读同一份输入、各处理一片数据
#   ⚠️ 标记为「强指示」：DPU.16416 的语义未独立确认（判据见 docs/134 §6 #1）
