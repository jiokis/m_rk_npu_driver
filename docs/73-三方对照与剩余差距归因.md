# 73 · 三方对照：闭环成立，剩余差距**归因到激活量化**

> 接 [docs/72](72-第一个端到端闭环成功.md)。本轮做最终检验：把三个来源放在一起比。

---

## 0. 三方对照（同一份输入、同一个 probe4）

```
onnxruntime 浮点参考   : [181.9662,  0.]
我的仿真器（仅权重量化）: [183.3684,  0.]     ← 与浮点差 1.402
官方模拟器（w8a8 全量化）: [177.2787,  0.]     ← 与浮点差 4.687

我的仿真器 vs 官方模拟器 : 差 6.090
```

## 1. ★ 差距可归因，而且归得干净

| 对比 | 差值 | 解释 |
|---|---|---|
| 我 vs 浮点 | **1.402** | **= 权重 INT8 量化误差的理论上界 1.4285**（docs/72）✅ |
| 官方模拟器 vs 浮点 | **4.687** | **> 1.43** ⇒ 官方还量化了**激活**（w8a8 的 a8） |
| 我 vs 官方模拟器 | **6.090** | = 上面两者之和的量级（激活量化的贡献） |

**⇒ 剩余差距不是「我的实现有错」，而是「我只实现了权重量化、没实现激活量化」。**

这正好对应下一步工作项 **CVT requant**（`.cfg` 里每个张量都有 `scale` / `zero_point`，
激活侧的参数是现成的）。

---

## 2. 这个结果对「闭环是否成立」的意义

**闭环仍然成立**，因为：

* 我的仿真器与**浮点参考**的差 **正好等于权重量化的理论误差** ⇒ 权重路径无误；
* 与**官方模拟器**的差**大于**权重误差、且方向合理 ⇒ 差异来自我**尚未实现**的那一层，
  而不是来自我**实现错了**的那一层。

**⇒ 三个数互相解释，没有「无法归因的残差」。**

## 5. 教训（本轮新增）

1. **★★ 三个数互相解释，比两个数吻合更有说服力。**
   「我 vs 浮点 = 1.402 ≈ 理论 1.4285」已经很好；再加上「官方 vs 浮点 = 4.687 > 1.43」
   就**同时确认了「我对在哪」和「我还缺什么」**。
   **做对照时多找一个参照，能同时验证正确性与定位缺口。**
2. **★ 差距大于预期时，先看它是不是「缺了一层」。** 6.09 一开始像「我错了」，
   但一算官方与浮点的差是 4.687 ⇒ 立刻明白是**激活量化没做**，不是实现错。
   **差值的方向和大小要放在多个参照之间看。**
3. **★ 收口时把「已知缺口」写成可执行项，而不是「未完成」。** 本轮把 6.09 这个差值
   本身变成了下一轮的靶子 —— **一个被量化的缺口就是一个可验收的任务。**
