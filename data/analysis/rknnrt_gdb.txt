# ── 首次在 librknnrt 里下断 ──
#   gdb 脚本要点（aarch64）：
#     · `catch load librknnrt.so` 后再算基址（ASLR）
#     · base = text_load − 0x0a8490        ← aarch64 库的 .text vaddr（**不是** 0x11b260）
#     · 第一个参数寄存器是 **x0**（不是 rdi）
#
#   断点：RKNNSubGraph 的 7 个虚函数 0xe1698 0xe16a0 0xe5848 0xe3108 0xe8cf0 0xe16b8 0xe1718
#   结果（resnet18，core_mask=0x7）：
#     命中位置：0xe1718, 0xe3108, 0xe5848, 0xe16b8
#     不同的 this 值：**2 个**（0x555614b100, 0x555614b780）
#   ⇒ **resnet18 在运行期只有 2 个 RKNNSubGraph 实例**
#   ⇒ 而它的提交数是 5、段数也是 5
#   ⇒ **所以 `RKNNSubGraph` ≠ 「提交段」** —— 这两个概念不是一回事
#   ⚠️ 命中都发生在对象**析构**附近（0xe5848/0xe3108 是析构路径，docs/139 §3）；
#      构造走的是非虚路径，所以「2 个」是**实例数下界**，不是创建次数
