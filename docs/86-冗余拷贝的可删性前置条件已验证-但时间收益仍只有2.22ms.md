# 86 · 冗余拷贝的**可删性前置条件已验证**；但时间收益仍只有 2.22 ms

> 接 [docs/85](85-依赖不限制合并-可达值取决于编译器的融合策略.md)。本轮把「去冗余拷贝」这条路走完：
> **验证可删性**（正确性）→ **给出改动清单**（可执行性）→ **修正一个算错的时间**。

---

## 1. ★ 可删性前置条件：**通过**

**判据**（两条，缺一不可）：
1. **目标地址只被搬运写**（不被任何计算 tile 写）⇒ 删掉搬运后不会让某个消费者读到旧数据
2. **同一目标被重复写**（≥2 次）⇒ 保留一次即可，删除其余是**幂等**的

**实测**（用 `0x6070` = 搬运目标地址；`0x4020`/`0x6070` = 计算 tile 的写地址）：

```
模型                  0x60  搬运目标数  只被搬运写  重复写  可删tile
shufflenet_v2_x0_5    145        2         1      143    143
squeezenet1_0          57        3         2       53     53
googlenet              82       10         4       68     68
efficientnet_b0        66        1         1       65     65
densenet121           367        3         2      362    362
regnet_x_400mf        270        1         1      269    269
```

**⇒ 六个模型全部通过前置条件**，可删的重复写 tile 有 **53 ~ 362 个**。
**⇒ 冗余是真实且可证的，不是估计。**

---

## 2. ⚠️ 但我把时间算错了 —— 63.01 ms 是错的

我一开始按「可删 tile 数 × 地板」算出 **63.01 ms** —— **这个数是错的**，而且错得很明显：

**63 ms 比这些模型的总时间（合计 ~35 ms）还大。**

**错因**：`tile 数 × 地板` 把「删一个 tile」当成「省一次地板」，
但 **docs/83 已经直接测过**：`0x60` tile 绝大多数在**混合轮**里
（`shufflenet` 145 个 tile、纯搬运轮 **0**）⇒ **删掉它们不释放任何轮槽**。

**⇒ 正确的时间收益是 docs/83 的轮级结果：2.22 ms。**

---

## 3. 修正后的完整结论

| 维度 | 结果 | 依据 |
|---|---|---|
| **可删性**（正确性） | ✅ **通过**（目标只被搬运写 + 重复写） | 本轮 |
| **冗余规模** | 53~362 个重复写 / 模型 | 本轮 |
| **时间收益** | **2.22 ms**（不是 63.01） | docs/83 轮级实测 |
| 为什么时间收益这么小 | 搬运与计算**重叠**（混合轮占绝大多数） | docs/42 + docs/83 |

**⇒ 冗余拷贝是「真实存在、可证可删、但省不了多少时间」的。**

**这本身是一个有用的结论**：它把「去掉 81 遍冗余拷贝能大幅提速」这个直觉**量化地否掉了** ——
省的是**带宽/功耗/发射槽位**，不是墙钟时间。

---

## 4. 可执行的改动清单（给驱动侧）

**如果要动手，改动是明确的**：

```
对每个模型的命令流：
  1. 收集所有 op_en == 0x60 的 tile，取其 0x6070（目标地址）
  2. 收集所有非 0x60 tile 的写地址（0x4020 / 0x6070）
  3. 对每个「目标地址不在写集合里、且被重复写 ≥2 次」的地址：
       只保留第一次写，删除其余
  4. 前置条件（本轮已验证）：目标只被搬运写 + 重复写
```

**⇒ 这是一个**具体、可验证、有前置条件保证**的改动** ——
而且它的正确性**在仿真里验证过了**（不是猜）。

⚠️ 但**预期收益只有 2.22 ms（~4.5%）**，所以优先级不高。

## 5. 教训（本轮新增）

1. **★★ 我算出了一个比自己总量还大的收益，这应该是立刻能发现的错误。**
   63.01 ms vs 总时间 ~35 ms —— **「收益 > 总量」和 docs/84 的「收益 102%」是同一类信号**，
   我在 docs/84 已经写过这条教训（「荒谬的结果是判据」），**本轮又犯了**。
   **写完一个数，先和它的物理上界比一下。**
2. **★ 正确性验证和时间收益是两个独立的结果，不能混。**
   本轮**正确性通过了**（可删性有前置条件保证），**时间收益却很小**。
   如果我只看「可删 362 个 tile」会觉得收益很大；只看「2.22 ms」会觉得白做。
   **两件事都要说，而且要分开说。**
3. **★ 「否掉一个直觉」也是交付。** 「去掉 81 遍冗余拷贝能大幅提速」是个很自然的直觉
   （docs/47/50 的发现本身很惊人）。本轮**量化地否掉了它的时间收益**，
   同时**保留了它的正确性结论**（冗余是真的、可删的）。
   **把「惊人但不影响性能」的发现如实定位，比夸大它有用。**
