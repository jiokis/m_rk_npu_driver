## 1. 检查结果：**不可行**，两个独立原因

```
gdb 是否安装：        无 gdb
段表：               只有 .dynsym（1671 项），**没有 .symtab** ⇒ 符号表被剥离
符号里的 TilingPass： 0（symtab 与 dynsym 都是 0）
.rodata 里的 RTTI：   有（N4rknn14RKNNTilingPassE 在文件偏移 0x1a8d760）
```

| 原因 | 影响 |
|---|---|
| **① 本机没装 gdb** | 直接无法下断点（装 gdb 需要 root 或从 .deb 解包，成本另计） |
| **② 符号表被剥离** | 即使有 gdb，`break RKNNTilingPass::run` 也**找不到符号**；要靠 `.data.rel.ro` 里的 vtable 做 RTTI 考古，再反汇编 |

**⇒ 这条路不是「难」，是「需要先解决两个前置问题，然后再做深层反汇编」。**

1. **★★★ 「可行性检查」要在承诺之后**立刻**做，而不是先做一半再说。**
