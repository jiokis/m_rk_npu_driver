# m_rk_npu_driver — RK3588 NPU 逆向工程

> 目标：**摸清 RK3588 NPU 的硬件接口，挣脱闭源工具链的限制**，把模型部署的自由度和优化空间拿回来。
> 状态：`阶段一 · 资料搜集与 ABI 测绘`（进行中）

---

## 为什么做这个

RK3588 的 NPU（3 核 / 6 TOPS）官方栈是这样的：

```
你的模型 ──► rknn-toolkit2 (闭源编译器) ──► .rknn 模型
                                              │
                                    librknnrt.so (闭源运行时)
                                              │  ioctl
                                    drivers/rknpu  ← GPL，开源 ✅
                                              │
                                           NPU 硬件
```

**上面两层闭源**，带来三个硬约束：

| 约束 | 具体表现 |
|---|---|
| **算子集固定** | 编译器不支持的算子只能回退 CPU，或整个图编译失败 |
| **调度不透明** | 无法控制算子如何映射到三核、何时 DMA、能否乒乓重叠 |
| **量化受限** | 实测 w4a16 在 RK3588 上被工具链直接拒绝（只能 w8a8），无法自定义量化粒度 |

而**内核驱动是 GPL 开源的** —— 这是整个逆向工作的立足点。

## 核心洞察

读驱动源码得到的结论（详见 [docs/02-内核驱动UAPI.md](docs/02-内核驱动UAPI.md)）：

> **内核驱动完全不解析命令流。** `struct rknpu_task` 只带一个 `regcmd_addr`，
> 驱动把 task 结构 DMA 过去、写几个控制寄存器、等中断就完事了。

这带来一个干净的分工：

- **控制面已被开源**：怎么分配内存、怎么提交任务、怎么同步 —— 6 个 ioctl 全部公开
- **数据面仍需逆向**：`regcmd` 那段字节码的格式只存在于闭源 `librknnrt.so` 和硬件里

所以路线是：**用开源驱动当发射器，把闭源运行时的真实命令流抓下来当样本，反推格式，然后自己造弹药。**

这意味着 **不需要改内核**，也不需要替换驱动 —— 在用户态就能做完全部工作。

## 目录结构

```
rk3588-npu-re/
├── docs/
│   ├── 01-资料搜集.md        社区已有成果、论文、先例（避免重复劳动）
│   ├── 02-内核驱动UAPI.md    ★ 逐行读源码所得：ioctl / 结构体 / 寄存器布局
│   ├── 03-寄存器与regcmd.md  命令流格式的逆向进展
│   └── 04-实验记录.md        每次实验的条件、命令、原始输出、结论
├── src/
│   ├── analysis/             源码静态分析工具（提取结构体、算 offset）
│   ├── probes/               抓取工具（strace 封装、ioctl 追踪、内存 dump）
│   └── poc/                  最小可运行程序（自己提交命令流）
├── data/
│   ├── dumps/                抓到的命令流样本（原始二进制 + 说明）
│   └── traces/               ioctl 调用序列
├── vendor/rknpu-6.1/         Rockchip 内核驱动头文件副本（GPL-2.0，仅作 ABI 参照）
└── scripts/autopush.sh       定时推送（防止成果丢失）
```

## 硬件与软件基线

| 项 | 值 |
|---|---|
| 板子 | Orange Pi 5 Plus 16G（RK3588） |
| 内核 | 6.1.99-rockchip-rk3588（vendor） |
| NPU 驱动 | v0.9.8 |
| 设备节点 | `/dev/dri/renderD129` |
| NPU 频率档位 | 300 / 400 / 500 / 600 / 700 / 800 / 900 / 1000 MHz |
| 用户态运行时 | `librknnrt.so` 2.3.0（闭源） |
| 编译器 | rknn-toolkit2 2.3.2（闭源） |

实测基线（供后续对比）：YOLOv5s 640×640 三核 **36.1 FPS / 27.72 ms**。
